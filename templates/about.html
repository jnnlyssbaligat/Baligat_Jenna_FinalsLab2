About the Portal

Heavenly Learning Portal is a practice project that shows how one shared layout can power every page of a site.

Our Mission

To make learning web development clear and approachable, with consistent design, readable pages and working examples.

How this site is built

  • One base.html holds the header, navigation and footer.
  • Each page extends it and fills only the content block.
  • A single stylesheet in the static folder styles every page.
